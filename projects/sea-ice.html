Hudson Bay Sea Ice Monitoring

Automated geospatial processing pipeline for daily Arctic sea ice observations. The project demonstrates data acquisition, GIS processing, quantitative analysis and automated publication workflows using Python.

Source code: github.com/Chris010980/hudson_bay_sea_ice_showcase

Project Overview

Scientific satellite products are automatically downloaded from NSIDC, processed using Rasterio and GeoPandas, analysed for several predefined Arctic regions, and exported as publication-quality figures and machine-readable datasets.

The pipeline is fully reproducible and intended for unattended daily execution.

Processing Pipeline

  1. Automatic download of daily NSIDC GeoTIFF products
  2. GeoTIFF validation
  3. Polar stereographic processing
  4. Region masking using GeoJSON polygons
  5. Ice coverage statistics
  6. Automatic generation of figures
  7. Export of CSV and latest.json
  8. Deployment to GitHub Pages
