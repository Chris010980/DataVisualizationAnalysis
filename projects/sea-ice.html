Hudson Bay Sea Ice Monitoring

Automated geospatial processing pipeline for daily Arctic sea ice observations. The project combines automated data acquisition, GIS processing, quantitative trend analysis and automated publication workflows — backed by 291 automated tests, static analysis and CI quality gates.

Project Overview

Daily satellite products are automatically downloaded from NSIDC, processed using Rasterio and GeoPandas, analysed for five predefined Arctic regions, and exported as publication-quality figures and machine-readable datasets.

The archive currently covers more than four decades of daily observations (about 79,000 GeoTIFF products) and the pipeline is fully reproducible, intended for unattended daily execution.

Processing Pipeline

  1. Automatic download of daily NSIDC GeoTIFF products, atomically and with retries
  2. GeoTIFF validation
  3. Polar stereographic processing
  4. Region masking using GeoJSON polygons
  5. Ice coverage statistics, climatology and trend analysis
  6. Automatic generation of all figure products
  7. Export of CSV products and latest.json
  8. QA validation of the complete output tree
  9. Deployment to GitHub Pages

from src.analysis.timeseries_analyzer import (
    compute_linear_trend,

def test_noisy_fit_matches_hand_calculation() -> None:
    """Least-squares fit of (1,1), (2,2), (3,4).

    slope = 1.5, intercept = -2/3, R² = 27/28 (hand values).
    """
    x = np.array([1.0, 2.0, 3.0])
    y = np.array([1.0, 2.0, 4.0])

    slope, intercept, r_squared = compute_linear_trend(x, y)

    assert slope == pytest.approx(1.5)
    assert intercept == pytest.approx(-2.0 / 3.0)
    assert r_squared == pytest.approx(27.0 / 28.0)

Quality Assurance

Every change passes mandatory CI quality gates (ruff lint and format checks, pytest with coverage) before it reaches the production branch. The suite currently comprises 291 automated tests in 45 files with 96 % line coverage, organized into five test levels from isolated unit tests to full end-to-end pipeline runs.
