Scientific Computing & Geospatial Analysis

  • Hudson Bay Sea Ice Monitoring

    Automated processing pipeline for more than four decades of daily satellite-derived sea ice observations. The project combines automated data acquisition, GIS processing, regional masking, statistical evaluation and publication-quality visualisations with daily updates. It is developed with a mandatory quality gate: 291 automated tests across five test levels, 96 % line coverage and CI-enforced static analysis.

    Testing & Quality Assurance →

    Python • Rasterio • Cartopy • GeoPandas • NumPy • Matplotlib • PyTest • CI/CD

  • Population Density Mapping

    Multi-scale population density visualisations using multiple cartographic projections with emphasis on projection correctness, reproducibility and publication-quality figures.

    Python • Cartopy • GIS • Raster Data • Scientific Plotting

  • Effective Electron Potential in the Helium Atom

    Numerical visualisation of a simplified two-electron quantum-mechanical model illustrating electron-electron interaction and effective potentials through static figures and animations.

    Python • NumPy • Scientific Computing • Physics • Matplotlib
